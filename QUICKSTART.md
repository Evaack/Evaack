# 🎰 Quick Start - Poker Advisor

## 🚀 **Launch the App on Your PC**

### Option 1: Simple Command (Recommended)
```bash
npm start
```
This will automatically open your browser!

### Option 2: Use the Start Script
**On Linux/Mac:**
```bash
./start.sh
```

**On Windows:**
```
start.bat
```

### Option 3: Manual
```bash
npm run dev
```
Then open your browser to: http://localhost:5173

---

## 🎮 **Using While Playing Poker on Your Phone**

**Setup:**
1. Launch the app on your PC (see above)
2. Position your PC monitor where you can glance at it
3. Start playing poker on your phone
4. Keep the poker advisor open in your browser

**Quick Workflow (5 seconds per hand):**
1. **Look at your cards on phone** → Press `Q` on PC, type hand (e.g., `AKs`)
2. **Flop comes** → Click the 3 flop cards quickly on PC
3. **See recommendation** → Glance at BIG action text on screen
4. **Make your move** → Act on your phone based on advice
5. **Next hand** → Press `N` to reset (positions auto-rotate!)

---

## ⌨️ **Essential Keyboard Shortcuts**

| Key | Action |
|-----|--------|
| `Q` | Quick hand entry - Type AA, KK, AKs, QJo, etc. |
| `N` | New hand - Resets everything, rotates positions |
| `H` or `?` | Help menu |

---

## 💡 **Pro Tips for PC + Phone Combo**

1. **Keep browser fullscreen** on one monitor for easy glancing
2. **Use quick entry (Q)** - Way faster than clicking cards
3. **Memorize shortcuts** - N for new hand, Q for quick entry
4. **Pre-set pot/bet** - Update as action happens
5. **Trust the big text** - The recommendation is HUGE for quick reads
